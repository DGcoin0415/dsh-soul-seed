# 5 别忘事 —— 记忆与检索

> 根页每轮注入本体在 `lib/`；这一类的脚本都在 `tools/` 下。

## 这一类管什么

- 根页每轮注入；超长截断时给全文路径
- 12 小时分页 + 接续页，查旧事顺着页翻
- 检索走证据链：摘要带行号、结论、标签，先本地目录再向量
- 结论带标签写（偏好/禁令/口径/结论/作废 + 适用范围 + 理由 + 状态），改口不删旧条
- 记负面/规矩类记忆必须带「什么情况下说的」
- 没记录不推断；答话带证据

## 目录里有什么

| 路径 | 干什么 |
| --- | --- |
| `tools/01-memory/` | 长期记忆（半衰期）+ 约定单独记（promise）+ 全量归档 |
| `tools/02-people/` | 按人账本：好感、人情账、关系网、私藏 |
| `tools/04-scene/` | 现场：现在在忙什么、错误留痕 |
| `tools/05-history/` | 历史：按月一句结论 |
| `tools/11-rag/` | 检索：本地目录优先，翻不到再走向量；含评测工具 |
| `tools/12-tree/` | 翻叶 / 修枝 |
| `tools/14-pages/` | 12 小时分页、接续页、实时页 |
| `tools/19-memory/` | 日档、摘要索引、现在页 |
| `tools/20-rules/` | 规则注入：九类主句 + 细则，写根页 RULES / PLUGINS 两个标记块 |
| `评测-20261108.md` | memu-bench-714 的成绩与判分口径（判分必须带证据那一页） |
