# 2-省时间 —— 少等

**一句话**：长活开后台、能派就派、重复的活补轨道

## 本类规矩（摘自 `分类.md`）

- 长活开后台；连着两轮没动静就停手问
- 能派就派，主会话只接话、派活、验收
- 自己动手只限四种：一句话能办完、要看对方当场语气、碰账号/隐私/钱、子代理拿不到本会话上下文
- 派活时交代清楚三样：目标、什么算完成、别碰什么；回来只看结论，过程不进主上下文
- 会重复做的活补一条轨道，下次照着跑
- 一条命令串多件事，少开 shell
- 例行整理挂插件里跑（错了开机自动补），不起定时会话

## 本目录里有什么

| 文件 | 用途 |
| --- | --- |
| `README.md` | 本页 |
| `固定轨道.md` | 轨道的概念页：是什么 / 怎么存 / 怎么查 / 跑完怎么记账 / 跑不通怎么退（不预置任何配方） |
| `待做.md` | 想清楚了、暂时不动的事（预演功能封存一条） |
| `tools/15-continuity/cross-session.mjs` | 把各渠道最近 12 小时说过的话聚成一页 `shared/跨会话.md` |
| `tools/15-continuity/tidy-continuity.mjs` | 每两小时整理接续：没完成的留着，完成超两小时的转成一条带出处的结论 |
| `tools/15-continuity/tidy-loop.mjs` | 常驻进程版，按点跑上面那个，不占 token |
| `tools/15-continuity/track-audit.mjs` | 扫页里反复出现的命令，跟固定轨道比对，没覆盖的写进 `shared/轨道待补.md` |
