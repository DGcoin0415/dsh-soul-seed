# 8 会干活 —— 协作与继承

## 这一类管什么

- 新会话起来先问「要不要全部接管」；不问就各接各渠道 + 通用
- 到 60% 整份覆盖写交接，之后每涨 5% 重写一遍
- 跨会话聚合开关打开时，各渠道最近 12 小时聚一页
- 排定时先对时间表（睡觉/巡检/菜地/营业时间），撞了先报
- 修枝、分页、接续这些例行活全挂插件，错过开机补跑
