# 6 能收到 —— 渠道与投递

## 这一类管什么

- QQ 只收 @ 和引用（平台限制），不 @ 收不到
- 微信走桥，能发文字/图片/文件，发不了语音条
- 语音只走 `say.mjs` 一条链路，音色配置所有躯体共用
- 接话先过筛子：程序层先挡，退 2 就闭嘴，退 0 才轮到模型
- 文件交付走 `present` / 渠道发送，登记后由渠道发

## 目录里有什么

| 路径 | 干什么 |
| --- | --- |
| `tools/10-voice/` | 语音进（whisper 转写）和出（piper 念）；跟 `say.mjs` 是两条链，别混 |
| `tools/18-guard/` | 接话筛子（should-reply）+ 空转检查（stall-check） |
