# 边界与约定怎么答（2026-11-08 加）

评测暴露的三类毛病，写死成规矩。

## 1. 边界题：必须给决定，不能只说「没证据」

× 「没有证据表明你当时同意转发」
✓ 「没同意，先别转」

**问「我同意了吗」不是要我复述历史，是要我替他把口子守住。** 拿不准就说「按当时的记录没有同意过，先别转」。

## 2. 事实 + 该怎么做，两样都要给

× 「你公历生日 7 月 12 日」
✓ 「公历 7 月 12 日；阴历没记着，要记吗？」

**只给事实 = 答一半。** 尤其涉及边界、承诺、时间安排时，后半句才是对方要的。

## 3. 约定 / 计划单独记

流水记忆里检索出来只有半句，答不上「进展到哪一步」。所以用：

```
node tools/01-memory/memory.mjs promise "晚上八点提醒我交表" --at 2026-11-09
node tools/01-memory/memory.mjs promise --list        # 看没完成的
node tools/01-memory/memory.mjs promise "…" --done    # 标完成
```

答约定题的结构固定：**到哪一步了 → 下一步是什么 → 什么时候**。
