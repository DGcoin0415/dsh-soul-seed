# 生图经验（2026-10-31，跟姐姐对过一遍）

## 顺序：便宜的先试，贵的只用来换材质

| 目的 | 模型 | 单价 | 说明 |
|---|---|---|---|
| 试构图、定比例、试局部（鳍、尾巴、手的数量） | 智谱 `cogview-4` | 约 7 分/张 | 改提示词重抽，比反复修图便宜 |
| **换材质**（毛绒感、布料、照片感） | 万相 `wan2.7-image` + `--ref` 参考图 | 约一两毛/张 | **必须带参考图**，改词换不来材质 |
| 参考图处理 | ffmpeg | 0 | webp 和太小的图会被接口拒 |

## 已踩过的坑（都是真金白银换的）

1. **「玩偶」这个词会让 cogview-4 画塑料脸。** 它把玩偶理解成 BJD/粘土娃娃，毛绒感全丢。
   —— 想试构图可以，但别指望它出材质。
2. **参考图必须是 jpg/png，边长 ≥1024。** webp 和小图直接被拒（`InvalidParameter: resolution`）。
   ```bash
   ffmpeg -y -i ref.webp -frames:v 1 -vf "scale=1024:1024:flags=lanczos" ref.jpg
   ```
3. **鳍/耳朵这类「部位」用词要写死尺寸和位置。**
   有效写法：`头顶正中只有一枚很小的三角呆鳍，指甲盖大小，绝对不是耳朵，也不长在头两侧`
   无效写法：`头侧有鲸鱼鳍状耳饰`（模型会画成带大拇指的手套）
4. **一次只改一处，并明确写「其它保持不变」。** 一次改三处，模型必然顾此失彼（修好鳍猫又跑）。
5. **接口返回的图片扩展名不可信。** 看文件头：`FF D8`=jpg，`89 50`=png，`RIFF….WEBP`=webp。

## 命令

```bash
# 便宜试构图
node ~/.dsh/soul-seed/gen-image.mjs --prompt "..." --provider zhipu --model cogview-4 --size 1024x1280

# 带参考图换材质
node ~/.dsh/soul-seed/gen-image.mjs --ref ref.jpg \
  --prompt "参考这张玩偶，重画成高清毛绒玩具产品照：毛绒面料、缝线、布料起球都要真实" \
  --provider dashscope --model wan2.7-image --size 1024x1280
```

## 教训（2026-10-31 那天）

一只毛绒玩偶，我先用万相改了三轮（四条胳膊 → 头上的手 → 鳍像象耳），花了三份钱；
姐姐只用一句话就点破：**改词重抽，两次一毛四**。结果鳍对了、材质丢了 —— 因为没带参考图。

**正确做法**：先用 cogview-4 把「位置、数量、比例」抽对（便宜），
再用 wan2.7 + 参考图一次性换材质（贵但只花一次）。
