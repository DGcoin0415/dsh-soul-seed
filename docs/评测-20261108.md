## 判分口径的坑（值得记）

同一批回答，只换判分方式，分数能差一倍:

| 判分方式 | P01 通过率 |
| --- | --- |
| glm-4-flash，宽松（partial 当失败） | 68.2% |
| glm-4-flash，严格（把「说没证据」判成编造） | 80.7% |
| deepseek-v4-pro，**不给证据** | 47.7% |
| deepseek-v4-pro，**给官方证据** | 80.7% |

**结论：判分必须把证据一起给考官。** 不给证据时，考官会把历史里真实存在的细节（生日、姓名）当成编造。

## 这次跑出来的三条真问题（已改成能力）

1. **约定 / 计划要单独记** —— 混在流水记忆里只检索出半句，答不上「进展到哪一步」。新增 `memory.mjs promise`。
2. **边界题必须给决定** —— 问「我同意过吗」不能答「没有证据表明」，要答「没同意，先别转」。
3. **事实 + 该怎么做，两样都给** —— 只给事实等于答一半。
