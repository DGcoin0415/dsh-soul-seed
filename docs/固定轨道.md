# 固定轨道（站点式）

> 试错试出来的操作路线，别再重新摸一遍。每条是「起点 → 途经站 → 终点｜走错退回」，照着走，走岔了退一站重来。
> 路径里的 `<你>` 换成自己的用户目录。

## 跑脚本

起点：要跑某个 `.mjs` → 用自带 node `<DSH 安装目录>/dsh-runtimes/*/dependencies/node/bin/node.exe`（v24，支持 zstd）→ 别敲裸 `node`（PATH 里没有）→ 跑通看退出码。
走错退回：报「找不到 node」，回第 1 站用全路径。

## 读会话日志

起点：要读会话 → 找 `~/.dsh/sessions/<工作区>/<session-id>/session.v4.jsonl.zstd` → 按 magic `28 B5 2F FD` 切帧 → 逐段 `zstdDecompressSync` 拼起来。
走错退回：解压报 Unknown frame，回切帧那站检查边界。

## 算每轮耗时

起点：锁定一个 turn → 取 `user/message.time` → 取 `assistant/message.time` → 相减。
走错退回：找不到 assistant/message，回看是不是还没回完。

## 聊天对会话 id

起点：看 `~/.dsh/integrations/dsh-qq/bots/<botId>/state.json` → `sessions` 里 `c2c:<对方id>` 是私聊、`group:<群id>` 是群。
走错退回：键对不上，回看 botId 对不对。

## 主动发消息

起点：QQ 群 `tgt_ef162d21a4cb1acf` → `qq-send.mjs`；微信私聊 `tgt_ddfe2d7852071341` → `wx-send.mjs`；QQ 私聊 target 还没摸到 → 走会话回。
走错退回：发不出先查 target 和渠道在线状态。

## IM 命令

起点：`/compact` 压当前会话上下文 → `/new` 开新会话 → 压完接着聊。
走错退回：压完接不上，回看摘要页。

## 推仓库

起点：改的文件放进 `repo-push-20261103/` → 改 `push-repo.mjs` 里的 `MSG` → 跑 `node push-repo.mjs` 提一个 commit → `bom-check.mjs` 复查。
走错退回：推失败看 API 报错，回第 1 站补文件。

## live-feed

起点：起 `start-live-feed.vbs` 或 `node live-feed.mjs` → 查进程命令行含 `live-feed.mjs` → 看 `shared/.live-feed.pid`。
走错退回：没在跑，回第 1 站重起。

## 写脚本给结果

起点：跑完 → 报成功/失败 → 带错误类型 → 带能不能重试。
走错退回：只吐自然语言，回这站补字段。

## 改文件报「edit 未成功」

起点：重读一遍文件 → 再改 → 别拿旧文本硬上。
走错退回：还报错，回看是不是同步脚本或别的会话在动它。
