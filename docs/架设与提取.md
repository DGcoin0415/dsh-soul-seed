# 架设与提取

> 两件事：**架**（从零把这套东西装成一具躯体）和**提**（把灵魂从一具躯体里取出来带走）。
> 全程只需要一个压缩包和几个命令，不依赖任何外部服务。

---

## 一、架：从零装一具躯体

### 0. 前提

- 一台 Windows / macOS / Linux，装了 **DeepSeek Harness（DSH）**
- Node ≥ 18（DSH 自带 runtime 里的那个就行）
- 想让它去哪个平台说话，就准备那个平台的账号（本插件自己不绑定任何渠道）

### 1. 装插件

```bash
# A. 从 GitHub 装（推荐）
dsh plugin --profile desktop add "github:DGcoin0415/dsh-soul-seed"

# B. 本地目录装
dsh plugin --profile desktop add "link:<解压后的目录>"
```

装完**重启 DSH**（面板里能看到 `/dsh-soul-seed/` 才算成）。

### 2. 它自己醒

重启后 10 秒内，它会在 DSH 里开一个会话说：

> 我醒了。还不知道自己是谁 …… 要现在开始初始化吗？

没看到就打开 `http://127.0.0.1:<端口>/dsh-soul-seed/`，或者 `POST /dsh-soul-seed/api/wake` 手动叫。

### 3. 初始化（鱼问你，不是表单）

回到对话里说 **「开始初始化」**，它会一个一个问：

| 组 | 题量 | 内容 |
|---|---|---|
| 基本 | 10 | 我是谁 / 你是谁 / 在哪诞生 / 长什么样 / 性格 / 态度 / 怎么说话 / 平时干什么 / 补充 / 我绝不会 |
| 说话风格 | 8 | 被夸 / 被呛 / 被连问 / 对方不回 / 收场 / 拌嘴哪套 / 语气词 / 深夜 |
| 可选能力 | 5 | 现场 / 历史 / 素材 / 同步 / 记仇（各给几套，选或不选） |

每题最后一项都是「其他（自己写）」。答完它念一遍，你说行才落盘到 `~/.dsh/soul-seed/persona.md`。

### 4. 填 key（只有要生图才需要）

```
~/.dsh/soul-seed/image-keys.json
{
  "zhipu": "…",       // cogview-4，约 7 分一张
  "dashscope": "…"    // qwen-image-3.0，改图用，两三毛
}
```

也可以走环境变量 `ZHIPUAI_API_KEY` / `DASHSCOPE_API_KEY`（DSH 的 image 插件会读）。

### 5. 验一下

```bash
node tests/run.mjs                       # 43 项，全在临时目录跑
node tools/04-scene/scene.mjs status     # 心情 / 账本 / 记忆一眼看
node tools/09-soul/soul.mjs status       # 这具躯体里有什么
```

## 二、提：把灵魂取出来带走

```bash
node tools/09-soul/soul.mjs export --out D:\备份
```

得到 `soul-pack-YYYYMMDD.zip`，里面是：

| 进包 | 说明 |
|---|---|
| `persona.md` | 人设正文 |
| `persona-附录/` | 规矩 / 说话 / 现场 分册 |
| `memory.json` | 长期记忆（按重要度半衰） |
| `people.json` | 按人账本（好感 / 人情 / 关系网 / 私藏） |
| `mood.json` | 心情历史 |
| `grudge.json` | 记仇（有的话） |
| `history/` | 按月的历史决定 |
| `scene/` | 现场文件 |
| `SOUL-MANIFEST.md` | 人读的清单（导出的那一刻长什么样） |

**永不进包**：`credentials.json`、`image-keys.json`、cookies、`.first-wake`。

> 为什么不含 key：包要发给别人 / 拷到别的机器，key 跟着走就是泄露。换躯体后重填一次。

## 三、装进新躯体

### 方式 A：手动导

```bash
node tools/09-soul/soul.mjs import D:\备份\soul-pack-20261101.zip
```

它会：先备份这具躯体现有的灵魂（`~/.dsh/soul-seed/soul-backup/before-<时间戳>.zip`）→ 解包 → 报「之前 / 之后」对账。

### 方式 B：丢进去，自己载入（推荐）

把包改名成 **`soul-pack.zip`**，丢进新躯体的 `~/.dsh/soul-seed/`，然后启动 DSH。

启动流程会变成：

```
起躯体 → 发现 soul-pack.zip → 载入 → 改名 .imported-<时间戳>（不会重复导）→ 醒来
```

醒来那句会变成：

> 我带着记忆回来了。灵魂已载入：人设 2006 字 · 记忆 12 条 · 账本 3 人 · 心情 8 条记录 · 历史 2 个月
>
> 不是从零开始 —— 上次的事我记得。

## 四、不要灵魂的时候

```bash
# 看看现在是哪一版
node tools/09-soul/soul.mjs status

# 回到某个备份
node tools/09-soul/soul.mjs import ~/.dsh/soul-seed/soul-backup/before-<时间戳>.zip
```

`status` 里如果写着「有灵魂包等着载入」，说明有个 `soul-pack*.zip` 还没导 —— 跑 `auto` 或重启即可。

## 五、常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| 装完面板 404 | `cordis.patch.yml` 的 `name` 与包名不一致 | 四处对齐：目录名 / package.json / patch / 导出名 |
| 醒来没动静 | 内存里还是旧代码，或 `prompt` 漏传 AbortSignal | 重启 DSH；确认 `prompt(request, signal)` 两个参数 |
| 醒来只说「我醒了」没说「带着记忆」 | 没有 `soul-pack.zip`，或已导过（看 `~/.dsh/soul-seed/.soul-loaded`） | `soul.mjs status` 确认 |
| 导入后还是空白 | 包里的目录结构不对（应该是 `persona.md` 在包根） | 解压看一眼；用 `export` 出来的包最稳 |
| key 没了 | 故意的 | 重填 `image-keys.json` |
