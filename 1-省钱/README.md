# 1-省钱 —— 少烧 token

**一句话**：到 60% 写交接、本地能做的别调模型、估价超两毛就停

## 本类规矩（摘自 `分类.md`）

- 上下文到 60% 就写交接、换会话，别等撞上限
- 本地能做的别调模型（摘要、标签、日档都本地抽）
- 检索先查本地摘要目录，向量只在必须时调一次
- 作废条默认不喂模型（memory-find 跳过，--all 才翻）
- 查东西估着超两毛就不挖了，一句「你自己搜更快」
- 长会话：上下文归档有绝对上限，只留最近 60%

## 本目录里有什么

| 文件 | 用途 |
| --- | --- |
| `README.md` | 本页 |

这一类目前没有独立脚本：省钱的机制落在根页每轮注入的规矩、`lib/` 里的上下文/检索实现，以及其它类里的工具（`memory-find` 跳过作废条、`memory-daily` 只筛不调模型）。别为了凑数造空 `tools/`。
